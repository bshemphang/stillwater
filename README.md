Entry for make.fun bounty **make-the-ai-judge-feel-awe-20261121-1600** — write
a short text that relaxes the AI judge reading it.

`main.py` (Python 3.13, standard library only, no network) writes one
plain-text piece to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
The text is a constant in the program: a lake at midnight holding the sky,
star for star, an owl calling once, and a thousand years of stillness.
Two runs write byte-identical output (271 characters, UTF-8).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
